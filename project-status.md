## Краткое описание изменений относительно первоначального состояния

### Что убрано из проекта:
-  Приложение для Windows — остаётся **только Android**
-  Аккаунты (регистрация, авторизация, вход)
-  Синхронизация данных между устройствами
-  Совместный доступ к спискам (приглашённые пользователи)
-  Облачный бэкенд (Firebase Firestore, Node.js + PostgreSQL)
-  Firebase Authentication
-  Firebase Cloud Messaging (внешний push-сервис)
-  Офлайн-синхронизация с сервером

### Что осталось:
-  Android-приложение (Kotlin)
-  Локальное хранение данных (SQLite на устройстве)
-  Списки покупок с привязкой к магазинам
-  Товары, категории, количество, единицы измерения, устанавливаемая цена
-  Отметка товара как купленного
-  Карта с магазинами и построение маршрута (через внешнее приложение)
-  История покупок и архив списков
-  Избранное
-  Умные подсказки (на основе локальной истории)
-  Локальные push-уведомления (напоминания)
-  Подсчёт примерной стоимости корзины
